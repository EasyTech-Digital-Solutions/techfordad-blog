# Rules: Gift Guides Section

## Placement rules
* Content stays under the existing techfordad.com domain, never a new domain or subdomain
* Gift Guides must appear in the main navigation at all times, not only during peak season
* Homepage feature can change size or position by season, but must never disappear entirely

## Content rules
* Every guide post must link back to the central Gift Guides hub page
* Every guide post should include at least one contextual link from an existing tech review post where relevant
* Guides should be published and indexed at least a few weeks ahead of the relevant occasion (Christmas, Mother's Day, Father's Day, Grandparents Day)
* Prefer buying guide and comparison formats over general opinion posts, since these convert better for affiliate clicks

## Affiliate and tracking rules
* Use a dedicated tracking ID for all Amazon links inside Gift Guides content
* Do not mix Gift Guides links with the site's default or general tracking ID
* Confirm the tracking ID is active in Amazon Associates before publishing the first guide

## Amazon Associates compliance
* Every guide post must disclose the affiliate relationship clearly, per Amazon Associates operating agreement requirements
* Do not create a brand new Amazon Associates account for this section, it runs under the existing techfordad0b-20 account

## Review cadence
* Revisit which guides are ranking or converting after each major season
* Retire or rewrite guides that get no traffic or no clicks after two full seasons
