# Design: Gift Guides Section

## Navigation placement
* "Gift Guides" as its own top level item in the main nav bar, same visual weight as other main categories

## Hub page layout
* Page title: Gift Guides
* Short intro paragraph explaining what the section covers
* Grid or list of guide cards, each showing a title, one thumbnail image, and a one line description
* Cards link to their individual guide posts

## Homepage feature block
* Placed a few scrolls down from the top of the homepage, not above the fold
* During peak season (October through December, and around Mother's Day and Father's Day), move the block higher and make it visually larger, maybe with a seasonal banner or icon
* Outside peak season, block can shrink to a smaller single row or move further down the page

## Individual guide post layout
* Standard blog post template already used on the site
* Product recommendations formatted as a clear list or comparison table, not buried in long paragraphs
* Each product recommendation includes an Amazon affiliate link using the dedicated Gift Guides tracking ID
* A "See more gift ideas" link block at the bottom of relevant tech review posts, pointing to the closest matching guide

## Visual tone
* Match the existing TechForDad site theme and branding
* Keep imagery warm and approachable, consistent with a senior friendly, family gift giving tone
